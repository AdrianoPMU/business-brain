# Work logs

One file per task, named `YYYY-MM-DD-short-topic.md`. Several logs on the same day are fine; give each its own topic. Work done in other repos (like `agenda-llena`) is logged here too, with a name like `YYYY-MM-DD-app-short-topic.md`.

Write the log before your final reply on any task that changed something, then commit and push it. To answer "what did we do last week?", `git pull` and read the files from the last 7 days.

## Template

```markdown
# YYYY-MM-DD: Short topic

**Where:** repo, tool or client this touched

**Done**
- 

**Decided**
- 

**Open / next**
- 
```
